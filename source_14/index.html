```html CSS List
Các kiểu danh sách trong CSS

1. Danh sách không có thứ tự

  • HTML
  • CSS
  • JavaScript
  • Thiết kế web
  • Lập trình web
  • Cơ sở dữ liệu

2. Danh sách có thứ tự

  1. Bước đầu tiên
  2. Bước thứ hai
  3. Bước thứ ba
  1. Chuẩn bị
  2. Thực hiện
  3. Kiểm tra

3. Vị trí đánh dấu danh sách

  • Đánh dấu nằm bên trong dòng nội dung.
  • Đây là ví dụ list-style-position: inside.
  • Đánh dấu nằm bên ngoài dòng nội dung.
  • Đây là ví dụ list-style-position: outside.

4. Thuộc tính list-style rút gọn

  • HTML
  • CSS
  • JavaScript

5. Danh sách với màu sắc

  • Mục thứ nhất
  • Mục thứ hai
  • Mục thứ ba
```
